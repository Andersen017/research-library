# Research Library

Публичная библиотека аналитических и технических исследований. Материалы доступны по прямым ссылкам, но по умолчанию не предназначены для индексации поисковыми системами.

## Структура

- `index.html` — каталог исследований.
- `research/` — опубликованные исследования.
- `data/researches.json` — карточки материалов, показанных в каталоге.
- `robots.txt` — общий запрет обхода библиотеки поисковыми роботами.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Стандарт представления

1. Ключевой вывод.
2. Схема / алгоритм / карта взаимодействий.
3. Ключевые данные, сравнения и риски.
4. Подробное обоснование и источники.

## Правило публикации

По умолчанию новое исследование публикуется как **полноценная читаемая HTML-страница** с размещением основного текста, оглавления, таблиц, выводов и источников непосредственно на сайте. PDF и Markdown допускаются как дополнительные форматы и не заменяют HTML-отчёт.

1. Одновременно с HTML-публикацией **автоматически добавляется карточка** в `data/researches.json`, чтобы материал отображался в общем каталоге Research Library. Дополнительное согласование регистрации в каталоге не требуется.
2. Если специально согласован режим **«только по прямой ссылке, без карточки в каталоге»**, исследование не добавляется в `data/researches.json`. Это исключение, а не режим по умолчанию.
3. В HTML-страницы добавляется `<meta name="robots" content="noindex,nofollow,noarchive">`; `robots.txt` сохраняет общий запрет обхода. **Включение материала в каталог не означает разрешение индексации поисковиками.**
4. После сборки GitHub Pages проверяются прямая HTML-ссылка и, при обычной публикации, отображение карточки в каталоге и переход из неё на исследование.
5. Запрет индексации и отсутствие карточки в каталоге **не являются защитой доступа**: репозиторий публичный. Конфиденциальные, договорные, персональные и коммерчески чувствительные данные не публикуются без отдельного решения по доступу.
6. Если требуется реальный закрытый доступ, используется система с авторизацией; режим `noindex` для этого не подходит.
