# Research Library

Публичная библиотека аналитических и технических исследований. Материалы доступны по прямым ссылкам, но по умолчанию не предназначены для индексации поисковыми системами.

## Структура

- `index.html` — каталог исследований.
- `research/` — опубликованные исследования.
- `data/researches.json` — карточки материалов, показанных в каталоге.
- `robots.txt` — общий запрет обхода библиотеки поисковыми роботами.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Стандарт представления

1. Ключевой вывод.
2. Схема / алгоритм / карта взаимодействий.
3. Ключевые данные, сравнения и риски.
4. Подробное обоснование и источники.

## Правило публикации

По умолчанию новое исследование публикуется в режиме доступа по прямой ссылке:

1. В каждую HTML-страницу добавляется `<meta name="robots" content="noindex,nofollow,noarchive">`.
2. Прямая ссылка проверяется после сборки GitHub Pages.
3. Карточка добавляется в `data/researches.json` только по отдельному решению.
4. Запрет индексации не является защитой доступа: репозиторий остаётся публичным, поэтому конфиденциальные, договорные, персональные и коммерчески чувствительные данные не публикуются без отдельного решения по доступу.
5. Если нужен реальный закрытый доступ, материал переносится в систему с авторизацией; режим `noindex` для этого не используется.
