# Research Library

Публичная библиотека аналитических и технических исследований.

## Структура

- `index.html` — каталог исследований.
- `research/` — опубликованные исследования.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Стандарт представления

1. Ключевой вывод.
2. Схема / алгоритм / карта взаимодействий.
3. Ключевые данные, сравнения и риски.
4. Подробное обоснование и источники.

## Правило публикации

Публичный контур не предназначен для конфиденциальных, договорных, персональных или коммерчески чувствительных данных без отдельного решения по доступу.
